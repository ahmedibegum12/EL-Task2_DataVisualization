# Customer Personality Analysis Dashboard

## Project Overview

This project focuses on analyzing customer behavior, demographics, income patterns, and purchasing habits using data visualization techniques.

The main goal of this project is to understand customer segments and generate meaningful business insights that can help organizations improve their marketing strategies.

## Tools Used

- Tableau - Dashboard creation and data visualization
- Microsoft Excel - Data handling and preparation
- CSV Dataset - Data source

## Dataset Description

The Customer Personality Analysis dataset contains customer information such as:

- Age
- Education
- Marital Status
- Income
- Product Spending
- Marketing Campaign Responses

This data helps in understanding customer preferences and purchasing behavior.
